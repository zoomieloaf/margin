# Changelog

## 0.1.0

First release.

- Preview, Edit and Markdown modes in one tab (Ctrl/Cmd+E).
- Selection menu, toolbar, slash menu, Markdown typing shortcuts, block handles with drag and drop.
- Tables, GitHub callouts, highlights, to-do lists, outline panel with reading stats.
- Export to PDF (with the Edge or Chrome you already have) and HTML; copy as rich text or Markdown.
- Block-preserving saves: untouched blocks are written back byte-for-byte.
