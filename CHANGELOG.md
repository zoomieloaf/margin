## 0.1.0

First release.

- Markdown files open as clean pages: Preview, Edit and Markdown modes in one tab (Ctrl/Cmd+E).
- Selection menu, toolbar, slash menu, Markdown typing shortcuts, and blocks you drag around.
- Tables, GitHub callouts, highlights, to-do lists, and an outline with reading stats.
- Links between docs open as pages, with Back and Forward. Broken links are flagged, and a missing page is one click away.
- AI on any selection: with Copilot in VS Code, or through your editor's chat (Cursor included).
- Page width per file: narrow, normal, wide or full.
- Export to PDF (with the Edge or Chrome you already have) and HTML; copy as rich text or Markdown.
- Your file stays yours: untouched blocks are written back byte-for-byte, so git diffs show only what you changed.
