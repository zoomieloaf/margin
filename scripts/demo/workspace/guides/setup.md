# Setup

Harbor runs locally in a couple of minutes. You need Node 20 and Git.

## Steps

1. Clone the repository and install the dependencies.
2. Copy `.env.example` to `.env` and fill in the API token.
3. Start the dev server and open `http://localhost:4000`.

```bash
git clone https://example.com/harbor.git
cd harbor
npm install
npm run dev
```
